# Qwik City Lab ⚡️

Small Qwik City project kept as a framework lab.

## Stack

- Qwik 1.20
- Qwik City 1.20
- Vite 7.3
- TypeScript 6
- ESLint 9 flat config
- Prettier 3

## Requirements

- Node.js 22.12+
- npm 10.9+

## Run

```bash
npm install
npm run dev
```

## Validate

```bash
npm run check
```

This runs TypeScript, ESLint and a production Qwik build.

## Useful commands

```bash
npm run build
npm run preview
npm run fmt
```

Qwik documentation: https://qwik.dev/
